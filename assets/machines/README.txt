Amahle Blue — Machine Photos Directory
========================================

Please place your machine photographs in this folder:

1. Ribbon Blender:
   Filename: ribbon-blender.jpg (or .png / .webp)
   Path: assets/machines/ribbon-blender.jpg

2. Cage Mill:
   Filename: cage-mill.jpg (or .png / .webp)
   Path: assets/machines/cage-mill.jpg

Recommended format: JPG or WebP, landscape or 4:3 aspect ratio, min width 1200px.
The page `components/s-manufacturing.jsx` is configured to look for these two files.
If you use different filenames or extensions, simply update the `MACHINE_IMAGES` object
at the top of `components/s-manufacturing.jsx`.
